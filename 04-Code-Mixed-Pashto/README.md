# 04: Code-Mixed Pashto

This project investigates code-mixed Pashto and its interaction with other languages in real-world text.

- `data/raw/`: Original datasets
- `data/processed/`: Cleaned and prepared datasets
- `notebooks/`: Experiments and analysis
- `src/`: Reusable research code
- `results/`: Tables, figures, metrics, and reports
- `paper/`: Paper materials
