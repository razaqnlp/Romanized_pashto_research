# 01: Dataset Quality Analysis

This project investigates the quality, consistency, coverage, and preparation of datasets for Romanized Pashto NLP. It establishes the data foundation for the projects that follow.

- `data/raw/`: Original datasets
- `data/processed/`: Cleaned and prepared datasets
- `notebooks/`: Exploratory analysis
- `src/`: Reusable research code
- `results/`: Tables, figures, metrics, and reports
- `paper/`: Paper materials
